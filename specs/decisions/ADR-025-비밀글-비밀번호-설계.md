# ADR-025 문의 비밀글 비밀번호 설계 — 문자 집합·자릿수·해시 알고리즘

- **상태**: **제안 — 사람 확정 대기** ★ **첫 비밀글이 저장되기 전에 정해야 한다**
- **날짜**: 2026-07-31
- **관련**: `specs/006-inquiry/spec.md` ADR 후보 1·6 · `FR-015`~`FR-018` · `AC-25`·`AC-50` ·
  `SC-003` · `ADR-005`(계정 비밀번호 = Argon2id) · 요구사항 6.2
- **되돌리기 비용**: **최상** — **저장된 해시는 되돌릴 수 없다.**
  알고리즘이든 문자 집합이든 바꾸면 **모든 비밀글 작성자에게 비밀번호를 다시 받아야 한다.**
  그런데 문의글에는 *"비밀번호 찾기"* 가 없다 → **복구 수단이 아예 없다.**
- **합친 후보**: 006 후보 1(해시 알고리즘·파라미터) · 006 후보 6(문자 집합·자릿수).
  **둘 다 "같은 비밀 하나"에 대한 결정이고 서로의 입력이다** — 경우의 수가 정해져야
  해시를 얼마나 세게 걸지 판단할 수 있다.

---

## 맥락 — 계정 비밀번호와 위협 모델이 다르다

`ADR-005`는 **8~64자 계정 비밀번호**를 전제로 Argon2id를 골랐다. 여기는 다르다.

| | 계정 비밀번호(001) | **비밀글 비밀번호(006)** |
|---|---|---|
| 길이 | 8~64자 | **4자리** |
| 문자 집합 | 제한 없음(한글·이모지 포함) | **숫자 4자리** = 1만 가지 |
| 검증 빈도 | 로그인 시 — **드물다** | **열람할 때마다** — 잦다 |
| 복구 | (001에도 없다) | **없다** |

★ **두 가지가 동시에 나쁘다**: 값 공간이 1만이라 오프라인 전수조사가 **1만 번이면 끝나고**,
그렇다고 파라미터를 세게 잡으면 **정상 사용자가 열람할 때마다 그 비용을 낸다.**
파라미터를 올려서 얻는 것이 계정 비밀번호만큼 크지 않다.

★ **`AC-50`이 이미 문자열 처리를 요구한다** — `0000`이 유효해야 하므로 숫자로 다루면
앞자리 0이 사라져 값 공간이 1만보다 줄어든다. **문자열로 다루는 코드가 이미 있어야 하므로
영숫자로 넓히는 변경의 코드 비용은 생각보다 작다.**

## 검토한 대안

### 1. 문자 집합·자릿수

| | 경우의 수 | |
|---|---|---|
| **숫자 4자리** (요구사항 원문) | **10,000** | 사용자가 외우기 쉽다. **전수조사가 1만 번** |
| **영숫자 4자리**(대소문자 무시) | 약 **1,679,616** | **168배.** 요구사항 변경이지만 화면은 그대로 |
| 숫자 6자리 | 1,000,000 | 자릿수를 늘리는 쪽. 화면 요구가 바뀐다 |

**`SC-003`의 전제가 여기에 걸린다** — 값 공간이 1만이면 시도 제한(`ADR-026`)이 사실상
유일한 방어선이 되고, 시도 제한이 무력화되는 순간(서버 증설·재시작) 곧바로 뚫린다.

### 2. 해시 알고리즘·파라미터

| | |
|---|---|
| **`ADR-005`와 같은 설정 공유**(Argon2id 동일 파라미터) | 코드가 하나. **열람마다 계정 로그인급 비용**을 낸다 |
| **Argon2id, 파라미터를 따로**(더 가볍게) | 열람 비용을 낮춘다. **값 공간이 작아 어차피 파라미터로 지킬 수 없다**는 판단과 정합 |
| 빠른 해시(SHA 등) | **constitution 보안 요구사항이 금지**한다. 검토 대상 아님 |

## 권고

- **문자 집합**: 사람이 정한다. **영숫자 4자리를 권고**한다 — 코드 비용이 작고 168배다.
  다만 **요구사항 원문(숫자 4자리)을 바꾸는 것**이므로 사람의 승인이 필요하다.
- **알고리즘**: Argon2id 유지, **파라미터는 계정과 분리**하고 환경변수로 둔다.
  값은 7번에서 실측한다(`ADR-005`와 같은 처리).

## 남은 리스크

1. **`FR-008`(001)과 같은 종류의 구멍**: 알고리즘 종류는 규정되지만 **파라미터가 약한 상태는
   스펙상 위반이 아니고 AC로 검증할 수도 없다**(*"충분히 느린가"* 는 Given/When/Then으로
   쓸 수 없다). → **코드 리뷰(8번)의 몫**으로 남긴다.
2. 값 공간이 1만이면 **해시를 아무리 세게 걸어도 오프라인 전수조사를 막지 못한다.**
   DB가 유출된 시점에 비밀글은 사실상 공개다. **그 사실을 알고 4자리를 고르는 것인지**
   확인이 필요하다.
