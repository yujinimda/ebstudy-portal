## 1. 저장할 것 — 후보

PRD 와 받은 기획서에서 **"이건 어딘가에 남아 있어야 한다"** 싶은 것을 뽑았다.


| 이름              | 무엇                         | 왜 남아야 하나                    |
| --------------- | -------------------------- | --------------------------- |
| **회원**          | 아이디 · 비밀번호 · 이름 · 권한       | 로그인해야 하고, 글마다 누가 썼는지 알아야 한다 |
| **글**           | 제목 · 내용 · 조회수 · 쓴 날짜       | 게시판의 본체                     |
| **분류**          | 이름 · 순서 · 사용 여부            | 목록에서 분류로 걸러야 한다. 관리자가 추가한다  |
| **댓글**          | 내용 · 쓴 날짜                  | 자유게시판에만 있다                  |
| **첨부**          | 원래 파일 이름 · 저장 위치 · 크기 · 순서 | 자유게시판(파일) · 갤러리(이미지)        |
| **문의 답변**       | 내용 · 답한 날짜                 | 관리자가 문의 하나에 답한다             |
| **사용 못 하는 아이디** | 이름                         | 가입 때 막을 아이디 목록. 관리자가 관리한다   |

## 2. ★ 제일 큰 갈림길 — 게시판 4종을 어떻게 담나

**게시판이 4개인데, 표를 몇 개로 만들 것인가.**

이게 이 문서에서 제일 먼저 정해야 할 것이다. 뒤의 모든 것이 여기에 얹힌다.

### 4종이 서로 얼마나 같고 다른가

**같은 것** — 제목 · 내용 · 쓴 사람 · 조회수 · 쓴 날짜 · 목록에서 찾는 방식

**다른 것**


|              | 공지사항       | 자유게시판  | 갤러리 | 문의           |
| ------------ | ---------- | ------ | --- | ------------ |
| 분류           | 있음         | 있음     | 있음  | **없음**       |
| 첨부           | 없음         | 파일     | 이미지 | 없음           |
| 댓글           | 없음         | **있음** | 없음  | 없음           |
| 그 게시판에만 있는 것 | **맨 위 고정** | —      | —   | **비밀글 · 답변** |


### 갈래

**A. 표 하나에 다 넣고 "어느 게시판인지"를 칸으로 구분**

같은 것이 많으니 한 표에 넣는다. `게시판종류` 칸에 공지/자유/갤러리/문의를 적는다.
`맨위고정` 칸은 공지 글에만 값이 차고 나머지는 늘 비어 있다.

**B. 게시판마다 표를 따로**

공지표 · 자유표 · 갤러리표 · 문의표. 각자 자기한테 필요한 칸만 가진다.

**C. 같은 것은 한 표에, 다른 것은 게시판별 표에**

**답변: 이걸로 정하고 싶다.**

`글` 표에 공통 칸을 두고, `공지` 표에 `맨위고정`, `문의` 표에 `비밀글` 을 둔다.
글 하나가 두 표에 걸친다.

### 각각의 대가


|       | 좋은 점                                    | 나쁜 점                                                  |
| ----- | --------------------------------------- | ----------------------------------------------------- |
| **A** | 목록 찾는 코드가 한 벌. 메인 화면에서 4종을 한 번에 가져오기 쉽다 | **늘 비어 있는 칸이 생긴다.** "이 칸은 저 게시판에서만 쓴다"를 따로 지켜야 한다     |
| **B** | 빈 칸이 없다. 게시판마다 규칙이 명확하다                 | **댓글·첨부가 "어느 표의 몇 번 글"인지 가리켜야 해서** 연결이 깨진다. 목록 코드가 4벌 |
| **C** | 빈 칸도 없고 연결도 산다                          | 글 하나를 읽을 때 표 두 개를 붙여야 한다. 조금 느리다                      |


### 🔺 B 의 문제를 짚고 넘어가야 한다

답변: 댓글테이블을만든다면?  
이거 관련해서 b,c가 아직 정확히 어떤게 장점인지 모르겠어 근데 연결만된다면 b가 빠른거아냐? 빠른걸로 하고싶기도 하고 통상적으로 어떻게 하는건지도 좀 알아봐야겠어

댓글은 **"어떤 글에 달린 댓글"** 인지를 저장해야 한다.
표가 4개면 댓글이 `자유표 5번` 인지 `갤러리표 5번` 인지 구분할 방법이 없다.

데이터베이스에는 **"이 값은 저 표의 저 줄을 가리킨다"** 를 강제하는 장치가 있는데
(없는 글에 댓글이 달리는 걸 막아준다), **가리킬 표가 여러 개면 그 장치를 못 쓴다.**

첨부도 같다.
