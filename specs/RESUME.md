## 2. 환경 다시 띄우기

```bash
cd ~/project/edu/ebstudy-portal
docker compose up -d --build      # → http://localhost:3000
```

- **`.env` 는 커밋 안 된다.** 다른 기기면 새로 만들어야 한다:
  ```
  DB_URL=jdbc:postgresql://localhost:5432/portal
  DB_USERNAME=portal
  DB_PASSWORD=portal
  JWT_SECRET=아무거나-길고-무작위

  ADMIN_INITIAL_PASSWORD=AdminLocal2026!
  ```

  `docker-compose.yml` 의 `ports` 주석 2줄을 푼다
- 테스트 계정: `hong01` / `Study1234abcd` · 관리자 `admin01` / `AdminLocal2026!`

## 5. 다음에 반드시 할 검사 2개

### 5.1 파일 경계 위반 (내가 하기로 한 것, 아직 안 함)

코드 워크플로의 병렬 에이전트에게 *"네 패키지 밖은 건드리지 마라"* 를 **규칙으로만** 걸었다.
구조로 막은 게 아니라서 어겼는지 확인해야 한다.

```bash
git status --short backend/src/main/java/com/ebstudy/portal/common/
git diff --stat backend/build.gradle.kts frontend/package.json
ls backend/src/main/resources/db/migration/     # V11 이상이 생겼으면 위반
```

- `common/` 은 **백엔드 통합 단계만** 고쳤어야 한다
  (`ErrorCode` · `GlobalExceptionHandler` 는 통합 단계가 고친 것으로 보이나 미확인)
- `build.gradle.kts` · `package.json` 은 **아무도** 고치면 안 됐다
- 마이그레이션은 **V10 까지**가 기반 단계 산출물이다

### 5.2 코드 ↔ 스펙 어긋남

스펙이 코드보다 **나중에** 나왔다. 이미 하나 잡혔다:

- **`GET /api/categories` 가 401 이었다** (004 `AC-32` 는 "누구나 조회" 를 요구)
  → `SecurityConfig` 에 게시판 GET 허용이 들어간 걸 확인했으나 **실제 응답은 미확인**
- **`ADR-017` 관리자 권한**을 코드가 어느 쪽으로 구현했는지 대조해야 한다
