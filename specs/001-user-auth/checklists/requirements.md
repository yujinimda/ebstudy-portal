**의도적 예외 3건 (변경 없음)**

알고리즘 명시. constitution 원칙 II(검증 가능한 AC)와 보안 요구사항이 직접 요구하는 사항이므로
일반 명세 지침보다 우선한다. 근거는 각 항목에 기록됨.

**미해결로 남은 사항**
