| **티켓 식별 값에 SHA-256** | **constitution 위반이 아니다.** 보안 요구사항의 빠른 해시 금지는 **비밀번호 저장**에 한정되고, 그 근거(*"사람이 만든 값은 GPU로 초당 수십억 시도"*)가 **256비트 난수에는 성립하지 않는다.** 유지 조건을 함께 달았다: 정확히 32바이트 난수 · 원문 미저장·미로깅 · 만료·개별 무효화 · 해시 유일 인덱스 — **네 조건 모두 계획에 이미 있고**, `AC-35`(개별 무효화)·`AC-36`(미로깅)·5.5절(유일 인덱스)·5.6절(`BYTEA` 32바이트)이 각각 검증한다 |
| **구현 순서 1번에 공통 오류 처리** | **순서 자체는 타당하다.** 다만 *"전역 핸들러를 먼저 **완성**"* 은 성립하지 않는다 — 오류 경로는 기능이 생길 때마다 생긴다(Security 2번 · Validation·DB 4번). → **1번의 정의를 고쳤다**: *"독립 공통 인프라 구현"* → **"첫 실제 실패 경로(로그인 실패)에 포함된 기반"**. 어댑터는 해당 오류 경로가 생기는 단계에서 붙이고, **`AC-27`·`AC-28`의 전 오류 계약 매트릭스는 마지막에 한 번 훑는다**(그때가 모든 오류 경로가 존재하는 첫 시점이다). **위치는 그대로, *"완성한다"* → *"필요한 만큼 세운다"* 로만 바뀌었다** |

## 재검증하지 않는다 — 대가와 완화

`process.md` 5장 · constitution 개발 워크플로 공통 규칙.
**codex를 두 번 돌리지 않았다.** 1차 지적을 반영한 것이 통과다.

- **대가**: **수정이 지적을 제대로 해소했는지 아무도 확인하지 않는다.** 잘못 고쳐도 드러나지 않는다.
- **완화**: 위 두 표가 **지적 ↔ 수정을 1:1로 대응**시킨다. 나중에 *"이 문장은 왜 이렇게 됐나"* 를
  추적할 수 있다. 커밋 메시지에도 같은 내용을 남긴다.
- **특히 위험한 항목**(잘못 고쳤을 때 드러나기 어려운 순서):
  1. **필수 3(Argon2id)** — 파라미터를 7번에서 정하므로 **미확정이 하나 열린 채 게이트를 통과**한다.
     너무 낮게 잡으면 *"느린 해시를 쓴다"* 는 규칙이 형식만 남는다. **AC로 검증할 수 없다**
     (*"충분히 느린가"* 는 Given/When/Then으로 쓸 수 없다) → **8번 코드 리뷰의 몫**(`ADR-005` 리스크 3)
  2. **필수 1의 `FR-003`** — 원 요구사항의 의도를 **Claude가 추론했다.** 틀렸으면 AC 하나가 빠진다
  3. **권고 2의 CSRF** — 001에 AC가 없으므로 **자동 테스트가 없다.** `SameSite`가 코드에서
     빠져도 어떤 테스트도 실패하지 않는다 → **8번 코드 리뷰의 몫**
- 회고(10.7)에서 *"재검증을 생략해서 놓친 것이 있었나"* 를 추적한다.

## 이 게이트가 만든 값 — 정직한 평가

**3.5 게이트가 결함 4건을 잡은 것과 성질이 다르다.** 이번 지적의 절반은
**"계획이 스스로 한 주장이 사실이 아닌 것"** 이었다:

| 주장했던 것 | 실제 |
|---|---|
| *"AC 커버리지 33/33"* | 배정 계획이고 커버리지가 아니다. 게다가 **AC 없는 FR이 3개** 있었다 |
| *"4번으로 넘긴 과제 전부 해소"* | 넘겨받은 3건은 해소. **선언한 범위(인덱스·타입)는 비어 있었다** |
| *"가상 스레드를 켜서 막았다"* | OS 스레드 하나만. **DB 커넥션은 그대로** |
| *"`validate`가 결정적 근거"* | **순환 논증.** ADR 본문의 자기비판이 옳았다 |

**★ 이 네 줄이 이 게이트의 실질이다.** 자기 판정을 자기가 검토하면 이런 종류는 걸리지 않는다 —
**계획을 쓴 쪽과 판정하는 쪽이 같으면 "다 했다"는 문장이 검사받지 않는다.**
`process.md` 3장이 constitution을 도입하며 적은 것(*"규칙을 AI 기억에 두면 잊으면 그냥 어겨진다"*)
과 같은 구조이고, **이번에는 규칙이 아니라 "완료 선언"이 검사 대상이었다.**

**ADR 본문의 자기비판이 값을 했다.** `ADR-004`가 *"정직하게 적어둔다 — 이 근거는 순환에 가깝다"*
를 스스로 적어 뒀고, codex가 **독립적으로 같은 판정**을 냈다. 자기비판을 적지 않았다면
지적을 받고 나서 *"몰랐다"* 가 됐을 것이고, 적어 뒀기 때문에 **"알고도 넘어갔다"가 기록으로
남아 규칙 쪽을 고치는 데까지 갔다**(constitution 1.4.0).
→ `process.md` 4.1이 ADR에 *"몰라서 찍은 부분"* 을 남기라고 한 이유가 여기서 실증됐다.
